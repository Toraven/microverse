# 🧫 MicroVerse: Gut & Food Lab

Интерактивная образовательная платформа о влиянии питания на микробиом кишечника.

---

## 🚀 Быстрый старт

### Требования
- [Node.js](https://nodejs.org) версия 18 или выше

### Установка и запуск

```bash
# 1. Открой папку в терминале VSCode (Ctrl+` или Terminal → New Terminal)

# 2. Установи зависимости (один раз)
npm install

# 3. Запусти проект
npm run dev
```

После этого открой браузер по адресу: **http://localhost:5173**

## 🔬 Функции

| Вкладка | Описание |
|---------|----------|
| ⚗️ Калькулятор | Добавляй продукты → видишь влияние на микробиом |
| 📋 Дневник 24ч | Завтрак / Обед / Ужин / Перекус с прогрессом дня |
| 🎯 Рекомендации | Анализ дефицитов и что добавить в рацион |
| 🩺 Симптомы | Режим подбора питания по симптомам |
| 🧫 МедиаЛаб | Подбор питательных сред по патогену или образцу |

- 77+ продуктов в базе данных
- 8 бактериальных штаммов с анимацией
- Русский / English интерфейс
- Пребиотический индекс и пробиотики
- **Протоколы посева** — 5 клинических сценариев (ИМП, Сепсис, ЖКТ, Рана, Дых. пути)
- Поиск по артикулу среды

## 🛠 Для разработки

Основные файлы для правок:

| Файл | Что содержит |
|------|-------------|
| `src/App.jsx` | Весь UI, компоненты, переводы, логика |
| `src/data/media.js` | База питательных сред |
| `ARCHITECTURE.md` | Полная архитектура, схемы данных, state |
| `CLAUDE.md` | Правила работы с кодом для Claude |
| `PLAN/MEMORY.md` | Паттерны ошибок — читать перед правками |

Чтобы собрать продакшн-версию:
```bash
npm run build
```
