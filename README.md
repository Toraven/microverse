# 🧫 MicroVerse: Gut & Food Lab

Интерактивная образовательная платформа о влиянии питания на микробиом кишечника.

---

## 🚀 Быстрый старт

### Требования
- [Node.js](https://nodejs.org) версия 18 или выше

### Установка и запуск

```bash
# 1. Открой папку в терминале VSCode (Ctrl+` или Terminal → New Terminal)

# 2. Установи зависимости (один раз)
npm install

# 3. Запусти проект
npm run dev
```

После этого открой браузер по адресу: **http://localhost:5173**
